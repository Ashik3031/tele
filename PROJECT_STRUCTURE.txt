DATA FLOW DIAGRAM
=================

USER SUBMITS APPLICATION:

  Browser (React)                Backend (Node.js)           Database (MongoDB)
  ───────────────────           ─────────────────            ──────────────────
       |
       | Fills form
       | Selects PDF
       |
       v
    Submit button clicked
       |
       | POST /api/jobs/apply
       | (FormData with file)
       └──────────────────────────> Receives request
                                        |
                                        v
                                    Validates data
                                        |
                                        v
                                    Saves to MongoDB ────────> Stored in Cloud
                                        |
                                        v
                                    Saves PDF to
                                    backend/uploads/
                                        |
                                        v
                                    Sends response ────────> Success message


ADMIN VIEWS APPLICATIONS:

  Browser (React)                Backend (Node.js)           Database (MongoDB)
  ───────────────────           ─────────────────            ──────────────────
       |
       | Admin visits /admin
       v
    Admin Dashboard loads
       |
       | GET /api/jobs/all
       └──────────────────────────> Queries MongoDB ───────> Retrieves all apps
                                        |
                                        v
                                    Sends list back ───────> Shows in table
                                        |
                                        | User clicks to view
                                        v
                                    Returns detailed data
                                    + download links
                                        |
                                        v
                                    User can update status
                                    or delete


FILE UPLOADS:

  User selects PDF
       |
       v
  Frontend validates
  (PDF format, size < 5MB)
       |
       v
  Sends via FormData
       |
       v
  Backend multer middleware
       |
       v
  Validates again
       |
       v
  Saves to backend/uploads/
  with unique filename
       |
       v
  Filename stored in MongoDB
  with resume metadata

WHAT EACH FILE DOES
===================

Backend:
- server.js            Starts Express server, sets up routes
- models/...js         Defines MongoDB collection structure
- routes/...js         Defines API endpoints (/jobs/apply, etc)
- middleware/...js     Handles file uploads (PDFs)

Frontend:
- services/API.js      Communicates with backend
- AdminDashboard.jsx   Shows admin interface
- CareerFrom.jsx       Updated to send to backend
- AdminPage.jsx        Page wrapper for admin dashboard


ENVIRONMENT VARIABLES
=====================

  PORT=5000                          (Backend port)

Frontend (.env.local):
